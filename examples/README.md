# Examples

This directory contains practical integration examples for CI/CD and adapter usage.

Each example should fit into MartinLoop's current execution-control model rather than becoming a separate mini-control stack:

```text
DEFINE -> PREFLIGHT -> CONTROL -> VERIFY -> RECOVER -> PROVE -> ANALYZE
```

Use the examples to integrate a specific surface while keeping the canonical governed outcomes and receipt evidence consistent with the root product. For agent-readable context see [`../llms.txt`](../llms.txt) and [`../docs/for-agents.md`](../docs/for-agents.md).
