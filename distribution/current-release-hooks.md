# Current release hooks — 0.5.0 to 0.5.6

Use the hook that matches the community instead of listing everything at once.

- **Agent reliability:** fail-closed VERIFIED state; verifier evidence is run/workspace-bound.
- **Cost / FinOps:** hard spend and attempt ceilings; cost provenance stays actual/calculated/estimated/unavailable.
- **Autonomous coding:** provider-neutral governed autonomy; Codex capability negotiation uses the exact installed binary.
- **Recovery:** rollback fails closed when repository/file state cannot be proven.
- **MCP:** standalone MCP package, MCPB bundle, 22-tool surface, human-first proof output, official registry distribution.
- **Cross-platform:** Windows/macOS/Linux installer and packaged MCP startup hardening.
- **Observability / review:** dossiers, share receipts, run history, hosted metadata/evidence sync without source upload by default.
- **Failure diagnosis:** 13 runtime failure classes and improved launch/grounding diagnostics.
- **First-run UX:** `start`, `demo`, preflight admission, governed run, dossier/share lifecycle.

Do not combine these into a feature wall. Match one or two hooks to the audience and drive to install.
