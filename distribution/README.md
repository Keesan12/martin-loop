# MartinLoop distribution

This directory tracks OSS/MCP discovery work with one goal: turn high-intent discovery into installs and real governed runs.

Canonical install paths:

- CLI: `npx -y martin-loop@latest start`
- MCP: `npx -y @martinloop/mcp@latest`

Files:

- `discovery-status.json` — verified live/pending discovery surfaces
- `install-funnel.md` — conversion path from discovery to first run
- `claude-plugin-submission.md` — reusable Claude Code plugin directory payload

Do not mark a placement live until the external listing or merge is verified.
