# MartinLoop Claude Code plugin distribution

## Install

```text
/plugin marketplace add Keesan12/martin-loop
```

Then install the MartinLoop plugin from the marketplace, or use the MCP server directly:

```sh
npx -y @martinloop/mcp@latest
```

## Directory description

MartinLoop adds governed execution around Claude Code and other coding agents: hard spend/attempt limits, verifier-bound completion, recovery evidence, failure triage, and inspectable run receipts.
