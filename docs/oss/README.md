# Martin OSS Core

This repository is the public Martin Loop runtime surface: runtime packages, CLI, MCP server, examples, and release validation for the root `martin-loop` package.

## What the OSS actually does

MartinLoop is the execution-control system around coding agents. The coding agent performs the software work. MartinLoop governs the run from its Definition of Done through controlled execution, verification, recovery evidence, receipts, and post-run analysis.

```text
Definition of Done
  -> Controlled Run
  -> Verified Handoff
```

The connected lifecycle is:

```text
DEFINE -> PREFLIGHT -> CONTROL -> VERIFY -> RECOVER -> PROVE -> ANALYZE
```

The public runtime ends each governed run in one authoritative outcome family:

- `VERIFIED` when configured evidence supports the Definition of Done
- `STOPPED` when a configured hard boundary ends the run
- `NEEDS REVIEW` when completion cannot be established from the available evidence

This is intended to replace the patchwork around coding agents, not the coding agent itself. MartinLoop does not replace Git, CI, code review, security tooling, observability, or the host's model selection.

For agent-readable product context, see [`../../llms.txt`](../../llms.txt), [`../../llms-full.txt`](../../llms-full.txt), and [`../for-agents.md`](../for-agents.md).

## Public launch targets

- Install target: `npm install martin-loop`
- CLI target: `npx martin-loop`
- SDK target: `import { MartinLoop } from "martin-loop"`
- MCP target: `npx -y @martinloop/mcp`

## Validation commands

From the repo root:

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm test
pnpm oss:validate
pnpm public:smoke
pnpm --filter @martinloop/mcp smoke:pack
pnpm mcp:published:smoke:pack
```

For isolated end-to-end validation:

```bash
pnpm release:validate-local
pnpm release:matrix:local
```

## Notes

- The root `martin-loop` package follows the release line recorded in [`../release/VERSION-LEDGER.md`](../release/VERSION-LEDGER.md).
- `@martinloop/mcp` is published and released independently from the root package.
- Failure taxonomy is canonical runtime-derived from `FAILURE_CLASSES` in `@martin/contracts`; see [`FAILURE-TAXONOMY-13.md`](./FAILURE-TAXONOMY-13.md) and [`failure-taxonomy.runtime.json`](./failure-taxonomy.runtime.json).
- Use [`../release/VERSION-LEDGER.md`](../release/VERSION-LEDGER.md) before release work; it is the canonical version map for the root package and the standalone MCP package.
- `pnpm mcp:published:smoke` is a post-publish npm gate; use `pnpm mcp:published:smoke:pack` for local prepublish validation.
- The OSS boundary report is generated by `pnpm oss:validate` and written to this directory.
- Terminal motion and MartinLoop Arcade are presentation-only and cannot alter governed execution or evidence.
