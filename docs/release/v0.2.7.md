# MartinLoop v0.2.7

`martin-loop@0.2.7` republishes the root CLI and SDK package with cleaner package-page copy and release notes.

## What Changed

- The npm package now ships the cleaned README and package metadata from the public repo.
- The root release summary now explains recent shipped changes in plain public language on GitHub and in packaged docs.

## Why This Release Exists

The previous npm package page still reflected older README and release text. `0.2.7` republishes the root package so the npm page, packed tarball, and GitHub release history all match the cleaned public repo.

This patch does not change MartinLoop runtime behavior.

## Package Versions

| Package | Current public version |
|---|---|
| `martin-loop` | `0.2.7` |
| `@martinloop/mcp` | `0.2.5` |

`martin-loop` is the CLI and SDK package. `@martinloop/mcp` remains the standalone MCP server package.
