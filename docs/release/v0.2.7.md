# MartinLoop v0.2.7

`martin-loop@0.2.7` aligns the public GitHub repo and the published npm package on the same release state.

## What Changed

- The root package now ships with the same public-facing README, metadata, and release notes shown in the GitHub repo.
- Public release validation is stricter about internal process language and stray release artifacts in docs.
- The public release docs folder now contains only release notes intended for external readers.

## Why It Matters

This patch does not introduce new MartinLoop runtime features.

It makes the published package easier to trust because the public repo, GitHub release, and npm package page now describe the same shipped product surface.
