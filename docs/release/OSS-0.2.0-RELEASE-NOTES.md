# MartinLoop OSS `0.2.0` Release Notes

`martin-loop@0.2.0` ships the public OSS the first-value CLI slice slice.

## Included

- three-minute first-value path
- improved README and quickstart
- no-spend demo path
- `dossier --latest`
- receipt-oriented CLI output
- safer dossier fallback when older run records do not include first-value receipt fields

## Not Included

- install-profile tiers
- run triage
- Context Diet compact resources
- prompt pack
- hosted / remote MCP lifecycle
- operation surface, router, and autonomy claims
