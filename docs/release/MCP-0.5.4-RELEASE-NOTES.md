# @martinloop/mcp 0.5.4

MartinLoop MCP 0.5.4 brings governed-autonomous execution, shared outcome authority, and clearer proof surfaces to compatible coding-agent hosts.

## What changed

- MCP run input accepts the provider-neutral governed-autonomous intent and a finite provider execution timeout override.
- Codex runs reuse the exact capability profile and autonomy strategy proven during launch readiness.
- Human-readable Markdown appears first, with matching structured content and compatibility JSON retained for clients and integrations.
- Packed MCP artifacts include the shared presentation layer while excluding internal-only stub adapters and their exports.
- Package, server metadata, MCPB product metadata, and plugin configuration align on `0.5.4`; the MCPB manifest schema remains `0.3`.

## Install

```bash
npx -y @martinloop/mcp@0.5.4
```

The package supports Node.js 20 and newer. Release completion still requires the npm package, immutable `mcp-v0.5.4` tag, GitHub Release, MCPB assets, checksum validation, and official MCP Registry listing to be verified live.
