# MartinLoop 0.6.0 Public Promotion

This public staging branch promotes the reviewed 0.6.0 release from the validated private source of truth while preserving newer public-only dependency and packaging fixes.

## Customer-facing changes

- Non-blocking upgrade notices for outdated installs; governed work still proceeds and JSON stdout stays machine-readable.
- Verified Handoffs preserve successful verifier lifecycle evidence even when a budget boundary determines the final run outcome.
- MCP installation refreshes stale canonical MartinLoop entries while preserving unrelated host configuration.
- Empty run objectives fail before engine discovery or agent spend.
- `martin-loop demo` initializes a usable Git workspace automatically.
- The published root package now includes the runnable GitHub Actions budget-gate workflow.
