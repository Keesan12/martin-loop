# @martinloop/mcp 0.5.5

MartinLoop MCP 0.5.5 brings governed-autonomous execution and clearer proof surfaces to compatible coding-agent hosts.

## What changed

- MCP run input carries the provider-neutral governed-autonomous intent and an optional finite provider execution timeout.
- Codex runs reuse the exact capability profile and autonomy strategy proven during launch readiness.
- Human-readable Markdown leads each proof response, with matching structured content retained for clients and integrations.
- Verified Handoff authority is shared with the terminal experience, preventing conflicting outcomes across surfaces.
- Packed MCP artifacts include the shared presentation layer while excluding internal-only compatibility adapters.
- Package, server, MCPB, plugin, and generated host-install metadata align on `0.5.5`; the MCPB manifest schema remains `0.3`.

## Install

```bash
npx -y @martinloop/mcp@0.5.5
```

The package supports Node.js 20 and newer.
