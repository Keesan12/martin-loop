# MartinLoop OSS `0.2.5` Release Notes

`martin-loop@0.2.5` ships the stable cockpit slice for the public MartinLoop OSS package.

## Included

- stable `@martinloop/mcp@0.2.5` package metadata and server manifests
- discovery metadata and prompt/version stamps
- run triage and richer run inspection surfaces
- degraded run-store handling and selector validation hardening
- release guards, packed-surface smoke checks, and publish proof updates

## Not Included

- hosted services
- remote transport claims beyond the documented stdio path
- unrelated application packages or dashboards
