# @martinloop/mcp 0.8.0 — Swarm Evidence Alignment

The standalone MCP package advances with MartinLoop 0.8.0 and remains version-aligned with the root package, plugin metadata, and MCPB product version.

This release carries the provider-free contracts and evidence primitives used by the deterministic Swarm Mode demo. Provider-backed live Swarm execution is not exposed as a stable MCP capability in 0.8.0. The MCPB manifest schema remains `0.3`.
