# MartinLoop OSS `0.2.3` Release Notes

`martin-loop@0.2.3` ships the public OSS compact Context Diet receipts slice.

## Included

- `martin://runs/latest/summary`
- `martin://runs/latest/proof-card`
- `martin://runs/latest/budget-status`
- `martin://runs/latest/verifier-evidence`
- `martin://runs/latest/rollback-evidence`
- `martin://agent/next-step`
- compact-resource docs for low-context agents and hosts
- path-safety coverage proving compact payloads do not leak absolute local runs-root paths

## Not Included

- prompt pack aliases
- agent-start guide resource
- full-local profile generation
- shared analytics features outside the OSS package
