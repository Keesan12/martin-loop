# MartinLoop v0.2.6

`martin-loop@0.2.6` strengthens runtime safeguards and refreshes the root CLI and SDK documentation.

## What Changed

- MartinLoop now blocks a broader set of destructive verifier-command patterns before an agent run begins.
- Prompt and verifier-output integrity checks cover more high-signal override patterns before that text can re-enter the loop.
- Secret redaction and safe-path validation are tighter, which reduces the chance of leaking sensitive text or wandering outside the intended repo scope.
- Budget pricing and grounding-cache handling are more accurate and consistent.

## Why It Matters

This release is about making governed runs safer and easier to trust:

- fewer unsafe verifier commands make it past admission
- more suspicious prompt and output patterns are caught before another attempt runs
- run accounting is clearer when budgets depend on model choice
- public documentation better matches what the root package actually ships
