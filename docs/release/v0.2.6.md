# MartinLoop v0.2.6

`martin-loop@0.2.6` improves runtime safety and public package documentation for the root CLI and SDK package.

## Included

- stronger verifier-command blocking for destructive command patterns
- broader context-integrity scanning across task metadata and verifier output
- safer secret redaction and path validation
- model-aware budget pricing
- grounding cache invalidation improvements
- updated README, quickstart, workflow checks, and package metadata

## Package Versions

| Package | Current public version |
|---|---|
| `martin-loop` | `0.2.6` |
| `@martinloop/mcp` | `0.2.5` |

`martin-loop` is the CLI and SDK package. `@martinloop/mcp` is the standalone MCP server package.
