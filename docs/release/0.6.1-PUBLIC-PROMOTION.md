# MartinLoop 0.6.1 Public Promotion

This public staging branch promotes the reviewed 0.6.1 model-agnostic runtime from the validated private source of truth while preserving public-only packaging and dependency fixes.

## Customer-facing changes

- OpenAI-compatible models now perform governed workspace edits before independent verification.
- Native Codex, Claude Code, and Gemini CLI workers retain their existing execution paths.
- Kimi K2, Nemotron, DeepSeek, Qwen, Mistral/Codestral, compatible hosted routes, and local model servers use the common `openai` engine contract.
- Model-proposed paths are validated before writes; denied paths, traversal, malformed/no-op plans, duplicates, and symlink escapes fail closed.
- README and reference docs make the cross-worker support contract explicit.
